# Demo video script

Target length: **2:30**. Hard limit: under 3:00. Record the product, not slides. Use voice only or original/authorized audio.

## 0:00–0:15 — The problem

**Visual:** Open on the Aliigo Action Layer hero, then scroll to the one-publisher diagram.

**Voice:**

“Websites are built for people. Agents can scrape and click them, but they still have to guess what a business really offers, which facts are authoritative, and whether an action actually succeeded.”

## 0:15–0:30 — The idea

**Visual:** Hold on “Business knowledge + capabilities → Structured agent tools,” then reveal the two-business selector.

**Voice:**

“Aliigo Action Layer explores a reusable alternative. It publishes approved business knowledge and bounded capabilities as WebMCP tools. The agent researches and prepares; the person stays in control.”

## 0:30–1:12 — Luma workflow

**Visual:** Select Luma. Show the real WebMCP inspector with four registered Luma tools. Use the natural-language prompt or invoke `find_services`, then `prepare_booking`. Keep the website and inspector visible if possible.

**Voice:**

“At fictional Luma Wellness Studio, I ask for help with back tension, Friday afternoon, under one hundred euros. The agent calls narrow tools generated for this business: it matches an approved service, checks bounded availability, and prepares a booking.”

**Visual:** The website changes to **Ready to review — Therapeutic Massage — Friday at 16:30 — €85**. Point to provenance and activity.

**Voice:**

“The result appears in the website, with the approved catalog source and review date. The agent has not booked silently. I review the exact draft and confirm it myself.”

**Visual:** Click **Confirm booking**.

## 1:12–1:52 — Northstar workflow

**Visual:** Switch to Northstar and show the inspector tool set reconciling.

**Voice:**

“Now I switch to fictional Northstar Print & Sign. The same publisher removes Luma's tools and exposes a different capability set: print options, artwork requirements, and quote preparation.”

**Visual:** Use the Northstar prompt or invoke `prepare_quote_request`. Show the visible quote draft.

**Voice:**

“For five hundred premium event postcards, the agent compares approved stocks, checks the artwork specification, and prepares this A6 quote request. Again, I review and submit the consequential action.”

**Visual:** Click **Review and submit**.

## 1:52–2:18 — WebMCP and diagnostics

**Visual:** Open `/diagnostics`. Show support state, business, four expected/registered tools, and last structured result. Briefly show the `registerTool` code.

**Voice:**

“Under the hood, current `document.modelContext.registerTool` definitions use explicit JSON Schemas and bounded handlers. Abort signals reconcile tools on business switch. Diagnostics make support and execution inspectable, while unsupported browsers get an honest, clearly labeled simulation—not fake WebMCP.”

## 2:18–2:30 — Future

**Visual:** Return to the hero and trust cards.

**Voice:**

“This is a small deterministic demo of a larger possibility: make the long tail of business websites agent-ready, with approved facts, safe actions, and people still in charge.”

**End card:** Aliigo Action Layer · live URL · public repository.
